========================================================================
                      NASHEED STUDIO - PORTABLE EDITION
                    Professional Nasheed Video Automation
========================================================================

Welcome to Nasheed Studio!
This is a standalone Windows desktop application designed to create
high-definition Islamic Nasheed collection videos with customized
typography, active-track indicators, smooth animations, and audio transitions.

------------------------------------------------------------------------
NO PYTHON INSTALLATION REQUIRED
------------------------------------------------------------------------
This package contains a fully self-contained runtime including:
- Standalone Windows Executable: "Nasheed Studio.exe"
- Bundled FFmpeg and FFprobe media processing engine (located in tools/)
- Embedded UI graphics, typography engines, and default presets

------------------------------------------------------------------------
HOW TO RUN
------------------------------------------------------------------------
1. Double-click "Nasheed Studio.exe" in this folder.
2. The studio interface will open immediately.

------------------------------------------------------------------------
QUICK START GUIDE
------------------------------------------------------------------------
1. ADD BACKGROUND:
   - Go to the "Layout & Assets" tab on the right inspector pane.
   - Click "Choose background image…" and select your 16:9 wallpaper.

2. ADD AUDIO TRACKS:
   - Click "Add Tracks" in the left Playlist pane.
   - Select your MP3, WAV, or AAC audio files.
   - Arrange them in your desired playback sequence using Move Up / Move Down.

3. CUSTOMIZE LAYOUT & APPEARANCE:
   - Set Playlist alignment (Left, Center, Right) and columns (1 or 2).
   - Set Panel Opacity to 0% for a clean transparent floating track list,
     or increase opacity for a modern translucent glass backing.
   - Choose your Active Track Indicator: Animated Cursor, Glowing Highlight Pill,
     Accent Bar, or Underline.
   - Optional: Add a logo image and enable "Remove solid white / checkerboard background"
     for automatic transparent cutout.

4. EXPORT FINISHED VIDEO:
   - Select your export resolution (1080p Full HD, 1440p QHD, or 4K UHD).
   - Choose your Resource Profile:
     * Balanced: Optimal speed while keeping computer responsive.
     * Background-friendly: Quiet rendering with low CPU impact.
     * Maximum-speed: Uses all CPU cores for fastest export.
   - Click "Render MP4".

------------------------------------------------------------------------
USER DATA AND PREFERENCES
------------------------------------------------------------------------
Saved projects, reusable templates, and rendered videos are stored safely in:
   %USERPROFILE%\NasheedStudio\
Your configuration files and projects remain completely safe even if you
move or update the application folder.
