================================================================================
NASHEED STUDIO — HOW TO RUN AND CREATE DESKTOP SHORTCUT
================================================================================

HOW TO RUN:
Double-click "Nasheed Studio.exe" inside this folder to start the application.

HOW TO CREATE A DESKTOP SHORTCUT:
Double-click "Create Desktop Shortcut.bat" inside this folder.
A shortcut named "Nasheed Studio" will be placed on your Desktop.

IMPORTANT NOTE FOR WINDOWS USERS:
Do NOT drag, cut, or move "Nasheed Studio.exe" alone to your Desktop or another 
folder. Nasheed Studio is a standalone Windows application that relies on the 
runtime files located inside the "_internal" folder next to it. 

If "Nasheed Studio.exe" is moved out of this directory by itself, Windows will 
display an error stating:
"Failed to load Python DLL ...\_internal\python310.dll. LoadLibrary: The specified 
module could not be found."

To place an icon on your desktop:
Simply double-click "Create Desktop Shortcut.bat" or right-click "Nasheed Studio.exe" 
and select "Show more options" -> "Send to" -> "Desktop (create shortcut)".
